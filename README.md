# mathematical-biology

This repository contains an extra credit assignment completed at the end of my Mathematical Biology course. The project models disease transmission on a large network using simulation and analyzes how changes in infection probability affect the connectivity of the population.

Using Python, I generated a random network, simulated outbreaks across a range of infection probabilities, measured the size of the largest connected component after each simulation, and visualized the results to identify how network structure changes as an epidemic spreads.

Throughout this course, I learned to develop and analyze mathematical models of biological systems using difference equations, ordinary differential equations (ODEs), and partial differential equations (PDEs). Applications included ecology, physiology, neuroscience, epidemiology, and molecular biology. The course emphasized translating real-world biological processes into mathematical models, implementing computational simulations, and interpreting the resulting data.
